# Gomzo organic growth execution

Design freeze: no homepage app, CSS, fonts, layout or booking UI changes.

## Implemented
Explicit public crawler rules with private paths excluded. Admin robots blocks all. llms summaries. Service entity and current logo reference. FAQ schema derived from actual visible answers. Existing inventory-gated sitemap retained.

## Dependencies
Search Console and Bing ownership require authorized account verification. Never invent verification tokens, tracking IDs, reviews, addresses or endorsements. Verify genuine inventory/photos before publishing location and property pages. Check business profile eligibility before listing. No guaranteed rankings or AI recommendations.

## 12-week execution
1. Audit crawl access, canonicals and private boundaries.
2. Verify Search Console/Bing and submit sitemap; inspect key URLs.
3. Validate schema and llms endpoints.
4. Review existing guidance and crawlable links in existing styles.
5. Verify real homes and original photos for two neighbourhoods.
6. Publish approved property pages through verified inventory gate.
7. Measure mobile LCP/INP/CLS; optimize delivery without visual changes.
8. Establish eligible business profiles and official social identities.
9. Prepare researched Pune guides and relevant outreach drafts.
10. Collect genuine completed-stay reviews with consent.
11. Refine content using real Search Console query data.
12. Report qualified organic traffic, requests, confirmations and AI citations.

## Weekly metrics
Brand/nonbrand impressions, clicks, CTR; index coverage; property visits; organic booking request conversion; confirmed booking value; relevant referring sites; mobile field performance; fixed AI questions with dates and cited URLs. Never send guest names, emails, phone numbers or payment identifiers to analytics.
